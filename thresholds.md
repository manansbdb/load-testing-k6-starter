# Thresholds / Limiares

## English
- Start with smoke (few VUs), then average load, then stress/soak.
- Align `p(95)` / error rate with product SLOs.
- Never load-test production without explicit approval and safeguards.

## Português
- Comece com smoke (poucos VUs), depois carga média, depois stress/soak.
- Alinhe `p(95)` / taxa de erro com os SLOs do produto.
- Nunca faça load test em produção sem aprovação explícita e salvaguardas.
